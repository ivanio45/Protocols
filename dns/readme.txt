Документация к DNS-серверу с кэшированием
Этот код представляет собой простой DNS-сервер с кэшированием, который:
    Принимает DNS-запросы на указанном порту (по умолчанию 53)
    Проверяет наличие ответа в локальном кэше
    Если ответа нет в кэше, перенаправляет запрос к вышестоящему DNS-серверу (по умолчанию 8.8.8.8)
    Кэширует полученные ответы для ускорения последующих запросов

Система кэширования
    Кэш хранится в памяти и периодически сохраняется на диск
    Формат ключа кэша: (имя_домена, тип_записи)
    Значение кэша: список кортежей (данные_записи, время_истечения)
    Автоматическая очистка просроченных записей
    Сохранение кэша в файл (по умолчанию "dns_cache_custom_parser.pkl")


Запуск сервера
    Убедитесь, что у вас есть права на прослушивание порта 53 (или измените порт)
    Запустите скрипт: python cache_dns.py
    Для остановки нажмите Ctrl+C

После запуска сервера вы можете проверить его работу с помощью утилиты nslookup:
Базовый тест:
nslookup yandex.com 127.0.0.1
