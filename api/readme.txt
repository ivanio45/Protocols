
Этот скрипт предоставляет набор функций для работы с API ВКонтакте, позволяя получать различную информацию о пользователях и сообществах:
1)Получение списка друзей пользователя
2)Просмотр информации о пользователе
3)Получение последних постов со стены
4)Просмотр списка групп пользователя
5)Поиск общих друзей
6)Получение информации о сообществе
7)Просмотр участников группы


Использование:
    Получить список друзей текущего пользователя
    get_friends()

    Получить информацию о пользователе
    get_user_info()
    get_user_info('id') - информация о конкретном пользователе

    Получить последние посты
    get_last_posts(count=3)  # свои посты
    get_last_posts('id', count=3)  - посты другого пользователя

    Получить список групп пользователя
    get_groups()

    Найти общих друзей
    get_mutual_friends('id')

    Получить информацию о группе
    get_group_info('id')

    Получить список участников группы
    get_group_members('id', count=1000)
